# DEBER N°3 - Galería de Fotos

---

## TABS

- **Tab 1 - Galeria:** Muestra la cuadrícula de fotos tomadas y guardadas 
- **Tab 2 - Camara:** Se toma las fotografías directamente con la cámara del celular
- **Tab 3 - Estadísticas:** Un contador con las fotos que se tomaron en la app
